# Coding Guide
## Front-End
- 반응형 웹 (Mobile 기준, Desktop 확장)
- React.js 공식 홈페이지의 최신 가이드를 기준으로 작성.
- TDD
  - 단위 기능 개발전 JEST 먼저 작성
  - Strict Mode에서 중복 호출 제거
  - 과도한 Re-Rendering 발생하지 않도록 함.
- Props Type 지정
  - Component Props 지정하여 사용.
- Document 작성 대상
  - Component
  - Hooks
  - Page
  - Utils
  - Reducer
  - Thunks
  - Axios
